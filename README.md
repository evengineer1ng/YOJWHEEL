YOJWHEEL

A DIY sim-racing wheel built around two Nintendo Switch Joy-Cons and a 3D-printed wheel/faceplate.

The Joy-Cons slide directly onto rails in the 3D-printed faceplate, providing the wheel's button inputs without requiring separate switches or button electronics. They can also provide optional gyroscope input.

YOJWHEEL also supports SDL-based additive force feedback, allowing additional feedback effects to be layered into the driving experience.

Features

- Two rail-mounted Nintendo Switch Joy-Cons
- Joy-Con button inputs
- Optional gyroscope input
- SDL-based additive force feedback
- 3D-printable wheel and faceplate design

Hardware

The wheel and Joy-Con mounting system are designed to be 3D printed. Each Joy-Con slides onto integrated rails in the faceplate, making the controllers removable while retaining their buttons, sensors, and wireless connectivity.
